# M3：前端民宿搜索与比价页面

## 状态

已验收，后续开发已进入 M4。

## 模块目标

将 M2 的民宿查询与平台报价 API 接入 Vue 3，为用户提供可以实际操作的搜索、筛选、结果浏览和平台报价对比页面。本模块聚焦前端查询体验，不包含真实平台采集、用户系统、AI 推荐或旅行规划。

## 页面与路由

| 路由 | 用途 |
| --- | --- |
| `/` | 民宿搜索与跨平台报价比较首页 |
| `/status` | 保留 M0 的运行环境状态页面 |

## 已实现功能

- 默认加载大理演示数据，启动后无需手动填写即可看到结果。
- 城市、入住日期、离店日期和入住人数搜索。
- 日期前端校验，离店日期不晚于入住日期时阻止请求并显示提示。
- 无线网络、可做饭、停车位、海景设施筛选。
- 大理镇、双廊镇区域筛选。
- 入住总价上限筛选。
- 总价升序、总价降序和评分优先排序。
- 加载骨架、接口错误、无结果三类状态。
- 民宿结果卡片展示统一民宿、平台数、报价数、评分、设施和最低总价。
- 报价抽屉按总价对齐不同平台和房型，并拆分房费、清洁费、服务费和优惠。
- 抽屉支持背景点击、关闭按钮和 `Esc` 键关闭。
- 桌面端、平板和移动端响应式布局。
- 原运行状态页保留并可从主导航和页脚进入。

## 视觉方向

页面延续项目确定的松石绿、陶土橙和纸张米色，采用“旅行编辑部 / 价格研究桌”的视觉语言：

- 大字号宋体标题与紧凑的无衬线数据标签形成层级。
- 民宿卡片使用代码绘制的洱海、苍山和庭院抽象插画，不依赖外部图片服务。
- 结果卡片采用错峰进入动画，报价详情使用侧边抽屉转场。
- 页面背景保留路线虚线、柔和径向光斑和纸张质感。
- 移动端重新排列搜索表单、结果价格区和平台报价，而不是简单缩小桌面布局。

## 前端结构

```text
ListingSearchView
├── searchListings API
├── ListingCard
└── OfferDrawer
    └── getListingDetail API
```

- `src/api/listings.ts`：M2 接口调用和查询参数转换。
- `src/types/listings.ts`：搜索、民宿和平台报价 TypeScript 类型。
- `src/views/ListingSearchView.vue`：搜索状态、筛选条件和页面编排。
- `src/components/ListingCard.vue`：民宿摘要与最低价卡片。
- `src/components/OfferDrawer.vue`：跨平台报价明细。
- `src/utils/format.ts`：金额、日期和入住晚数格式化。

## 自动验证

- 默认搜索条件会在页面挂载后调用 API。
- API 结果能正确渲染民宿名称和最低总价。
- 设施按钮会更新选中状态并重新请求。
- 点击比较按钮会请求详情并打开报价抽屉。
- Vue 原有环境状态测试无回归。
- TypeScript 类型检查和 Vite 生产构建通过。

## 演示数据限制

- 当前有效报价日期为 `2026-10-02` 至 `2026-10-05`。
- 当前城市为“大理市”，平台报价均为演示数据。
- 民宿插画是页面视觉占位，不代表真实房源照片。
- 页面不会跳转到真实平台进行预订。

## 不包含

- 真实平台房源图片和实时价格采集。
- 地图模式和地理距离计算。
- 登录、收藏、历史记录和订单。
- 民宿个性化排序和 AI 推荐理由。
- 旅行计划生成与行程编辑。

## 验收步骤

1. 在项目根目录执行 `start-dev.cmd`。
2. 打开 `http://127.0.0.1:5173/`，确认默认显示 3 家大理民宿。
3. 确认最低总价依次为 `¥1,146`、`¥1,302`、`¥2,025`。
4. 点击“海景”，确认只显示“双廊”的 `DL_000003` 对应民宿。
5. 取消海景并选择“总价 ¥1,200 内”，确认只显示一条结果。
6. 恢复不限总价，点击第一家民宿的“比较平台报价”。
7. 确认报价抽屉显示 4 条报价，且费用和优惠明细完整。
8. 缩小浏览器宽度或使用移动设备模式，确认搜索表单、卡片和报价抽屉没有横向溢出。
9. 点击“运行状态”，确认仍可进入原环境检查页面。
10. 执行 `scripts\dev.ps1 test`，确认全部自动化检查通过。

## 通过条件

- 用户可以完成从条件输入、结果筛选到平台报价比较的完整前端流程。
- 页面状态与 API 返回一致，没有写死民宿结果或价格。
- 加载、错误、空结果和输入错误均有明确反馈。
- 桌面端和移动端的主要操作可见、可点击且无布局溢出。
- M0、M1、M2 已有功能没有回归。
