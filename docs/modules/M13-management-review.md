# M13：管理审核后台（数据进入正式业务前）

## 状态

待设计，暂不开发。

## 模块目标

承接 M4 导入产生的待审核民宿、平台房源和房型匹配结果。管理员确认后，房源才进入前端比价和推荐候选范围。

## 民宿新增流程

```text
JSON/CSV/授权 API
  ↓ M4
字段归一化、价格校验、同店/房型匹配
  ↓
待审核记录
  ↓ M13
管理员查看证据
  ├── 通过：进入可查询、可推荐数据
  ├── 驳回：保留原因，不进入业务候选
  └── 修正：修改统一民宿或房型关联后重新审核
```

## 计划功能

- 待审核民宿列表和批次筛选。
- 原始平台数据与归一化数据对照。
- 同店匹配分数、名称/地址/距离证据展示。
- 房型匹配证据和价格快照检查。
- 通过、驳回、修改关联和备注。
- 审核人、审核时间、审核前后值和操作原因审计。
- 只有审核通过的数据可进入 M2 查询和 M5/M8 推荐。

## 数据来源边界

- 优先接入平台开放接口、联盟接口、商家授权数据和正式合作数据。
- 开发阶段允许使用 JSON/CSV 演示文件。
- 不把未经授权的美团、途家、木鸟网页抓取作为正式数据方案。
- 不绕过登录、验证码、访问频率限制或平台反爬措施。

## 与其他模块的关系

- M1 提供民宿、平台、房型和价格基础表。
- M4 负责导入、归一化、匹配和审计记录。
- M13 负责人工审核和纠错。
- M2、M5、M6、M7、M8 只使用审核通过的数据。

## 当前不开发

- 管理员登录和角色权限（M12）。
- 审核页面和审核接口。
- 自动定时采集和消息队列。
- 未授权平台网页抓取。
