# M29 首页收藏闭环

M29 将 M28 的用户收藏能力接入首页搜索结果，让收藏从个人中心的独立功能变成完整的浏览流程。

## 功能范围

- 已登录用户进入首页时读取收藏列表，并在房源卡片上显示收藏状态。
- 用户可直接在搜索结果中收藏或取消收藏，操作结果同步到个人中心。
- 未登录用户点击收藏时不发起受保护请求，页面明确提示并提供 `/account` 登录入口。
- 单个房源提交期间禁用对应按钮，避免重复请求；接口失败时保留原收藏状态。

## 复用接口

```text
GET    /api/v1/users/me/favorites
PUT    /api/v1/users/me/favorites/{listing_public_id}
DELETE /api/v1/users/me/favorites/{listing_public_id}
```

本模块不新增数据库表或后端接口，继续复用 M28 的普通用户 Token 和收藏数据模型。

## 验收

1. 未登录打开首页，点击任意房源心形按钮，页面显示登录引导且不改变收藏状态。
2. 登录后返回首页，个人中心已有收藏的房源显示实心心形按钮。
3. 点击空心按钮后收藏成功，刷新页面状态仍保留，个人中心可看到该房源。
4. 点击实心按钮后取消收藏，刷新页面和个人中心均不再显示该收藏。
5. 收藏接口失败时页面给出错误提示，按钮恢复可用且原状态不变。
