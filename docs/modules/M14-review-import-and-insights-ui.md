# M14：评论导入与分析展示

## 状态

待验收。

## 模块目标

承接 M12 的评论主题与情绪分析能力，提供 UTF-8 JSON 评论导入流程，并在民宿平台报价抽屉中展示
最新分析快照。正式平台 API、联盟接口或商家授权数据后续可以转换成相同结构复用该流程。

## 导入命令

Windows 无需安装 make：

```powershell
.\scripts\dev.ps1 review-import
```

已安装 make 时也可以使用：

```text
make review-import
```

演示文件为 `backend/fixtures/reviews-demo.json`，包含 3 家演示民宿的评论。导入过程会：

1. 根据民宿公开 ID 找到统一民宿。
2. 以 `platform_code + external_id` 去重评论。
3. 保存新评论原文。
4. 使用 DeepSeek 或本地规则生成分析快照。
5. 如果整批评论都已存在，直接返回最近快照，不重复分析和消耗 Token。

## 查询接口

```text
GET /api/v1/listings/{listing_public_id}/review-analysis/latest
```

没有分析快照时返回 404，前端显示“暂无已审核的评论分析”，不会影响平台报价读取。

## 前端展示

打开民宿的“比较平台报价”抽屉后，会同时读取最新评论分析，展示：

- 评论样本数量。
- 正面、中性和负面比例。
- 最多 8 个评论主题。
- 每个主题的情绪和提及次数。
- 来自真实评论原文的证据。
- 本地降级或模型分析警告。

分析读取失败时，报价列表仍然正常显示。

## 数据边界

- 只导入有授权或用于开发的演示评论。
- 不绕过平台登录、验证码、反爬或访问频率限制。
- 评论分析不修改民宿评分和推荐排序。
- 单次导入沿用 M12 的 50 条、单条 2,000 字限制。
- 不保存完整 AI Prompt 或原始响应。

## 验收

1. 启动项目。
2. 执行 `.\scripts\dev.ps1 review-import`。
3. 打开 `http://127.0.0.1:5173`。
4. 点击任意演示民宿的“比较平台报价”。
5. 在报价列表下方查看“住客都在谈什么”。
6. 再次执行导入命令，确认返回原分析 ID，不新增重复评论和分析快照。

## 当前不包含

- 平台评论自动抓取。
- 管理员审核和修正评论主题。
- 评论翻译。
- 主题参与推荐权重计算。
