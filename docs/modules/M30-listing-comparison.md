# M30 多房源比较清单

M30 将首页原有的单房源平台报价抽屉与“我的比较”拆分为两个清晰流程：用户仍可查看一家民宿的多平台报价，也可以把不同民宿加入清单进行横向比较。

前端页面：`/compare`

## 功能范围

- 首页房源卡片增加“加入比较”操作，并显示是否已加入。
- 比较清单最多保存 3 家民宿，达到上限时给出提示。
- 清单保存在浏览器本地，刷新或切换页面后仍然存在，不要求用户登录。
- 比较页并排展示最低总价、每晚价格、住客评分、平台覆盖和主要设施。
- 用户可以移出单个房源或清空整个清单。
- 原 `/status` 环境状态页继续保留；首页“我的比较”导航改为 `/compare`。

## 数据边界

本期保存的是搜索结果快照和对应入住条件，不新增后端接口或数据库表。报价可能随采集数据变化；用户返回首页重新搜索后可以获得最新结果。

## 验收

1. 首页点击“加入比较”，按钮切换为已加入状态并显示查看比较入口。
2. 刷新页面后已加入状态仍保留。
3. 加入第 4 家时页面提示最多比较 3 家，原清单不改变。
4. `/compare` 正确展示各房源价格、评分、平台和设施差异。
5. 移出或清空后，比较页与首页状态同步更新。
