# M16：运营监控与数据质量看板

## 状态

待验收。

## 模块目标

为管理员提供只读运营视图，集中查看审核队列、最近导入、统一民宿与平台覆盖，以及 AI 模块的调用量。
统计直接读取已有业务表和轻量审计字段，不新增高频日志表。

## 接口

```text
GET /api/v1/management/dashboard
```

接口要求 `review_admin` 或 `super_admin` Bearer 令牌。

## 统计口径

- 审核队列：`pending`、`approved`、`rejected` 导入记录总数。
- 最近导入：最近 24 小时批次数、成功批次、失败/部分失败批次和记录数。
- 房源质量：active 统一民宿、active 平台房源和按平台覆盖数量。
- AI 使用：自然语言解析、推荐说明、旅行计划、评论分析的调用次数和 Token 总量。
- 数据警告：待审核记录、导入异常或没有 AI Token 消耗时显示提示。

所有指标都是当前数据库快照，不代表实时监控系统的秒级数据。

## 前端

```text
http://127.0.0.1:5173/management/dashboard
```

页面受 M15 管理员路由保护，可从审核后台点击“运营看板”进入。

## 容量边界

- 查询只做聚合计数，不保存新的事件明细。
- AI Token 从已有会话和分析快照的统计字段求和。
- 最近 24 小时导入通过时间条件查询，避免扫描历史原文。
- 后续数据增长后可为时间字段增加索引或汇总表，但不在本模块直接复制业务数据。

## 验收

1. 使用管理员账号登录。
2. 访问 `/management/dashboard`。
3. 确认看到待审核数量、平台覆盖和 AI 调用统计。
4. 执行一次 `data-import-review` 后刷新，待审核数量应增加。
5. 在审核台通过或驳回任务，再刷新看板，审核数量应变化。
6. 未登录访问接口应返回 401，不能读取统计数据。

## 当前不包含

- Prometheus/Grafana 秒级监控。
- 邮件、短信或企业微信告警。
- 自定义时间范围报表导出。
- 业务数据修改操作。
