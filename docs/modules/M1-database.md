# M1：MySQL 数据模型与演示数据

## 状态

已验收，后续开发已进入 M2。

## 模块目标

建立跨平台民宿比较所需的最小数据基础，明确“统一民宿、平台房源、房型、价格快照”之间的关系，并提供可重复初始化的演示数据。

## 本模块已实现

- SQLAlchemy 2.0 异步数据模型与统一命名约定。
- Alembic 异步迁移环境及首个数据库迁移版本。
- 美团、途家、木鸟三个平台的演示数据。
- 三个统一民宿、七条平台房源、八个房型及八条价格快照。
- 八项标准化设施及民宿与设施的多对多关系。
- 可重复执行的演示数据初始化脚本，重复执行不会重复插入数据。
- 一键启动时自动迁移数据库并初始化演示数据。
- 独立的 `db-migrate` 和 `db-seed` 开发命令。

## 数据表

| 表名 | 用途 |
| --- | --- |
| `platforms` | 平台基础信息，例如美团、途家、木鸟 |
| `canonical_listings` | 去重后用于平台间比较的统一民宿 |
| `platform_listings` | 某个平台上的原始房源及评分、评论数、来源链接 |
| `room_types` | 平台房源下可售的具体房型 |
| `price_snapshots` | 某房型在指定入住条件和采集时间下的价格组成 |
| `facilities` | 标准化设施字典 |
| `listing_facilities` | 统一民宿与设施之间的多对多关联 |

核心关系为：

```text
统一民宿 1 ---- N 平台房源 N ---- 1 平台
平台房源 1 ---- N 房型 1 ---- N 价格快照
统一民宿 N ---- N 设施
```

`price_snapshots.room_subtotal` 表示整个入住区间的房费小计，而不是单晚价格。总价计算规则为：

```text
总价 = 房费小计 + 清洁费 + 服务费 + 其他费用 - 优惠金额
```

## 命令

项目根目录安装 GNU Make 后可执行：

```powershell
make db-migrate
make db-seed
```

当前 Windows 环境未安装 Make 时，可执行等价命令：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File scripts\dev.ps1 db-migrate
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File scripts\dev.ps1 db-seed
```

`make start` 或 `start-dev.cmd` 也会在启动 FastAPI 和 Vue 前自动执行迁移和幂等初始化。
